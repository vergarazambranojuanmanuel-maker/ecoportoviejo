# EcoPortoviejo

Sitio web académico (HTML, CSS y JavaScript) sobre reciclaje, creado para la tarea
**Estándares W3C en el desarrollo web**.

- `index.html`: inicio
- `guia.html`: tabla de residuos y preguntas frecuentes (acordeón accesible)
- `contacto.html`: formulario con validación accesible

## Cómo verlo en local
Abrir `index.html` en el navegador (no requiere servidor).

## Estándares aplicados
HTML validado con Nu HTML Checker, CSS externo, HTML semántico, WCAG 2.2 AA,
diseño adaptable (legible a 320 px), `lang="es"`, sin manejadores en línea y con ARIA dinámico.
